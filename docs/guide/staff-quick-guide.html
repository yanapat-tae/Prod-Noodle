1ก่อนเปิดร้าน

  1. ต่อ Wi-Fi ร้าน และเปิดเสียงโทรศัพท์ให้ดัง
  2. เปิดเว็บด้านบน แล้วกด เข้าสู่ระบบ
  3. กด เปิดเสียงแจ้งเตือน แล้วเปิดหน้านี้ค้างไว้ทั้งวัน

2ลูกค้าสแกน QR สั่งเอง

  1. ได้ยิน 🔔 กระดิ่ง 2 ครั้ง = มีออเดอร์ใหม่
  2. กดแท็บ ห้องครัว ดูรายการ แล้วทำอาหาร
  3. ยกไปเสิร์ฟแล้ว กด เสร็จ/เสิร์ฟแล้ว

3ลูกค้าสั่งด้วยปาก

  1. กดแท็บ โต๊ะ / POS แล้วแตะเลขโต๊ะ
  2. กลับบ้าน กด + เปิดออเดอร์กลับบ้าน แล้วใส่ชื่อลูกค้า
  3. เลือกอาหาร แล้วกดส่ง ออเดอร์จะไปที่ห้องครัวเอง

4คิดเงิน

  1. โต๊ะ / POS → แตะเลขโต๊ะ → รับชำระเงิน
  2. เงินสด: เลือก เงินสด → กด ชำระเงินแล้ว
  3. โอน: เลือก PromptPay หรือ สแกนไทยช่วยไทย → ติ๊ก "ตรวจยอดเข้าจริงแล้ว" → ชำระเงินแล้ว
  4. ได้ยิน 🎵 เสียงไล่โน้ต = บันทึกรับเงินแล้ว

⚠️ ห้ามลืม

  1. ลูกค้าโอนเงิน: ดูในแอปธนาคารว่าเงินเข้าแล้ว ค่อยกดรับเงิน
  2. กดรับเงินแล้ว ไม่ต้องกดซ้ำ

5ปิดร้าน

  1. กดแท็บ ยอดขาย
  2. ดูยอดรวมวันนี้ หน้าร้าน กลับบ้าน เงินสด และเงินโอน

❓ ถ้ามีปัญหา

  1. ขึ้นว่า "ยังโหลดเมนูไม่ได้" → ต่อ Wi-Fi แล้วกด ลองอีกครั้ง
  2. ไม่มีเสียงกระดิ่ง → เพิ่มเสียงโทรศัพท์ แล้วกด เปิดเสียงแจ้งเตือน อีกครั้ง
  3. ใช้ไม่ได้เลย → จดกระดาษไปก่อน ร้านเปิดขายต่อได้ แล้วโทรหาผู้ดูแลระบบ
