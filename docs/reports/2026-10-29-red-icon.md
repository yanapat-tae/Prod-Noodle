# Red restaurant icon release

## Authorized design and delivery

The owner approved the noodle bowl, green chopsticks, golden noodles, rounded Thai
`โปรด` lettering and brick-red background, then explicitly requested deployment.
Only the background's outer corners were extended for a full-bleed square source;
iOS/browser launchers apply their own rounding. No food photos are introduced.

## Implementation plan

- [x] Preserve the approved master at `assets/branding/icon-master.png` and export
  opaque PNGs at 32, 180, 192 and 512px with `python scripts/generate-icons.py`.
- [x] Point favicon, iPhone touch icon and manifest at versioned PNG URLs.
  Use `purpose: any`: the artwork is not padded for the maskable safe zone.
- [x] Bump the service-worker cache and precache versioned icon/manifest URLs.
  Keep normal worker activation so open restaurant tabs are not forced to reload.
- [x] Run repository checks and local built-app icon/offline/browser verification.
- [x] Review the diff, push/merge the release and verify production asset bytes.

## Validation and deployment

PNG metadata checks passed: expected dimensions, opaque RGB, red at every corner;
all manifest icon targets exist and include the cache version. A separate reviewer
confirmed exact Lanczos exports from the approved master and no material findings.

- Node 24.19.0, pnpm 11.25.0, Pillow 12.3.0; frozen-lockfile install passed.
- `pnpm check`: exit 0; both typechecks, lint, 96/96 Node/PGlite tests, build and
  regenerated HTML passed. Generated `preview.html` is unchanged.
- A second Vite build using existing production public variables passed. The
  trailing slash on the configured Supabase URL is preserved exactly.
- `node /tmp/prod-icon-qa.mjs`: PASS on the production-configured local build.
  Simulated viewports 390×844 and 430×932, actual login heading visible, synthetic
  menu reads only, zero page errors and no horizontal overflow. Independent visual
  inspection confirmed readable Thai and visible login fields/button/link.
- Browser QA decoded every icon at its expected size; verified versioned
  HTML/manifest targets, removal of the legacy cache on normal activation and
  offline retrieval of all four icons after the next controlled navigation.
- `git diff --check`: passed. Application code, dependency manifests/lockfile,
  backend, data, QR links and theme colors have no changes.
