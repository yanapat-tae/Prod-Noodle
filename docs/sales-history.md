# ลบประวัติยอดขายที่ไม่ได้เกิดขึ้นจริง

บัญชีผู้ดูแลร้าน (เต้ / ปลั๊ก / พี่ปราง) เข้า `/admin` → **ยอดขาย** →
**จัดการประวัติยอดขาย** เลือกรายการที่กดทดลอง ระบุเหตุผล แล้วกด **ลบรายการที่เลือก**
ตรวจจำนวนและรายการอีกครั้ง ก่อนกด **ยืนยันลบประวัติ**

เลือกทีละรายการ หรือเลือกทั้งหมดที่แสดงได้ ประวัติแสดงทุกวัน รวมรายการยังไม่ชำระ
ไม่ได้จำกัดตามวันที่ของกราฟ หากมีคนรับเงินหรือแก้ข้อมูลระหว่างเลือก ระบบจะให้โหลด
ประวัติใหม่ก่อนลบ บัญชีพ่อ / ฟ้า / แม่ไม่มีสิทธิ์ลบ ทั้งหน้าจอ API และฐานข้อมูล

รายการที่ลบจะไม่นับในยอดขายรายวัน/เดือน ช่องทางขาย/ชำระเงิน กราฟ เมนูขายดี หรือ CSV
และออกจาก POS/ครัว การลบยอดทดลองไม่ใช่การคืนเงินให้ลูกค้า หากเป็นยอดขายจริงที่ต้อง
คืนเงิน ให้ใช้ฟังก์ชันคืนเงินตามเดิม

ระบบรักษาบิล ราคาเดิมและหลักฐานรับเงินไว้ พร้อมบันทึกผู้ลบ เหตุผล เวลาและรายการ
ในตาราง `sales_deletions` สำหรับผู้ดูแลระบบ การแสดงประวัติรุ่นทดลองจำกัด 1,000 รายการ;
หากเกินจะหยุดและแจ้งให้แบ่งข้อมูล ไม่มีการลบบางส่วนโดยไม่บอก

หากอินเทอร์เน็ตหลุด ให้กดยืนยันซ้ำจากหน้าต่างเดิม ระบบใช้คำขอเดิมเพื่อไม่ลบซ้ำ
ตรวจยอดและโหลดประวัติใหม่หลังสำเร็จ หากปิดหน้าไปแล้ว เปิดใหม่เพื่ออ่านผลล่าสุดก่อนเลือกอีกครั้ง
