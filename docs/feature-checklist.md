# รายการฟังก์ชันที่ต้องทำงานได้เสมอ

ใช้ตรวจทุกครั้งก่อนปล่อยงานที่เปลี่ยนการทำงานของเว็บ ทุกข้อต้องยังทำงานเหมือนเดิม
รายการนี้รวบรวมจากโค้ดและเอกสารของระบบ (README, acceptance-tests, รายงาน PR #3–#11)
เมื่อ 4 พ.ย. 2026

ผลของแต่ละข้อ: **ผ่าน / ไม่ผ่าน / ยังไม่ได้ทดสอบ**
ข้อที่มี 📱 ต้องทดสอบบน iPhone จริงด้วย การทดสอบอัตโนมัติอย่างเดียวไม่พอ

## A. ลูกค้าสั่งอาหาร

| # | ฟังก์ชัน | ผลที่ต้องได้ |
|---|---|---|
| A1 | สแกน QR โต๊ะ 1–8 | เปิดหน้าสั่งของโต๊ะนั้น ไม่ต้องกรอกชื่อ |
| A2 | QR กลับบ้านหน้าร้าน | ต้องกรอกชื่อ บิลแสดง "กลับบ้าน-ชื่อ" และเลขคิวที่เริ่มนับใหม่ทุกวัน |
| A3 | QR สั่งล่วงหน้า/ส่งใน LINE | สั่งแบบกลับบ้านได้เหมือน A2 |
| A4 | ส่งในหมู่บ้านเศรษฐสิริ วงแหวน-สุขาภิบาล2 | ติ๊กแล้วต้องกรอกบ้านเลขที่/ซอย และเบอร์โทรที่ถูกต้อง POS และครัวเห็นข้อมูลครบ |
| A5 | เมนู | แสดงทุกหมวดเป็นปุ่ม (ไม่ซ่อนใน dropdown) ค้นหาชื่อได้ ใช้อีโมจิ 🍜 แทนรูป |
| A6 | ตัวเลือกต่อจาน | ขนาด เส้น น้ำซุป ท็อปปิ้ง เพิ่มพิเศษ (เช่น ไข่ดาว +10) ค่าเริ่มต้นที่ถอดออกได้ (เช่น ถั่วลิสงในไอศกรีม) จำนวนตัวเลือกสูงสุด (เช่น ท็อปปิ้ง 3/4) |
| A7 | โน้ตอิสระต่อจาน | โน้ตตรงกันในตะกร้า POS และครัว ราคาไม่เปลี่ยน |
| A8 | ตะกร้า | เพิ่ม/ลด/ลบ และเห็นราคารวมก่อนส่ง |
| A9 | เก็บแบบร่าง | ย้อนกลับหรือโหลดหน้าใหม่แล้ว ตะกร้าและข้อมูลกลับบ้านยังอยู่ |
| A10 | ดูสถานะ | ลูกค้าเห็นสถานะออเดอร์ของตัวเอง |
| A11 | ราคาเชื่อถือได้ | เซิร์ฟเวอร์คิดราคาเอง ถ้าราคาที่ลูกค้าเห็นไม่ตรง ต้องปฏิเสธ ห้ามเชื่อราคาจากโทรศัพท์ |
| A12 | ส่งซ้ำไม่เกิดบิลซ้ำ | ถ้าส่งแล้วไม่รู้ผล ให้ลองใหม่ด้วยรหัสเดิมได้ แม้โหลดหน้าใหม่ ต้องได้บิลเดียว |
| A13 | เน็ตหลุด 📱 | ห้ามบอกว่าส่งสำเร็จถ้าเซิร์ฟเวอร์ไม่ตอบ ตะกร้ายังอยู่ |
| A14 | อ่านง่าย 📱 | ปุ่ม/แถวตัวเลือกสูงอย่างน้อย 56px ตัวอักษรหลัก 20px ช่องห่าง 12px ไม่ล้นจอที่ 390px และใช้ได้ที่ตัวอักษร 200% |
| A15 | ไม่มีลิงก์พนักงานในหน้าลูกค้า | พนักงานเข้า `/admin` โดยตรงเท่านั้น |

## B. POS และครัว (พนักงาน)

| # | ฟังก์ชัน | ผลที่ต้องได้ |
|---|---|---|
| B1 | เข้าสู่ระบบพนักงาน | อีเมล + รหัสผ่าน (Supabase Auth) มีบัญชีได้ 6 บัญชี บัญชีที่ปิดใช้งานเข้าไม่ได้ |
| B2 | สิทธิ์ 2 ระดับ | Owner (Full Admin) ทำได้ทุกอย่าง Staff ทำไม่ได้: จัดการเมนู คืนเงิน ลบประวัติ เปลี่ยน QR ดูโควตา ต้องกันทั้งหน้าจอ API และฐานข้อมูล |
| B3 | POS เปิดออเดอร์แทนลูกค้า | ทั้งโต๊ะและกลับบ้าน |
| B4 | ครัวเห็นออเดอร์ใหม่ทันที 📱 | อัปเดตเองโดยไม่ต้องรีเฟรช (Realtime) และกลับมาตรงเมื่อเน็ตต่อใหม่ |
| B5 | เสร็จ/เสิร์ฟแล้ว กดครั้งเดียว | จาก ใหม่/กำลังทำ/พร้อมเสิร์ฟ ออเดอร์ออกจากครัว แต่บิลที่ยังไม่จ่ายยังอยู่ใน POS |
| B6 | เสียงเตือน 📱 | กระดิ่งสองจังหวะเมื่อออเดอร์เข้า เสียงไล่โน้ตเมื่อรับเงินสำเร็จ มีปุ่มเปิดเสียงและลองฟัง ออเดอร์เข้าพร้อมกันหลายใบดังครั้งเดียว ปิดเสียงหรือออกจากระบบแล้วต้องไม่ดัง |
| B7 | รวมบิลหลายรอบของโต๊ะ | จ่ายครั้งเดียวครบทุกรอบ ถ้ามีรอบใหม่เข้ามาระหว่างกดจ่าย ต้องให้ตรวจยอดใหม่ |
| B8 | วิธีรับเงิน | เงินสด, PromptPay (พนักงานยืนยันว่าเงินเข้าจริง), ไทยช่วยไทย (ต้องกดยืนยันแยก) ไม่มีการตรวจเงินโอนอัตโนมัติ |
| B9 | กดจ่ายซ้ำไม่รับเงินซ้ำ | retry ได้ใบเสร็จเดิม |
| B10 | คืนเงินเต็มจำนวน | เฉพาะ Owner และต้องคืนเงินก่อนยกเลิกออเดอร์ที่จ่ายแล้ว |
| B11 | ยกเลิกออเดอร์ | ตามลำดับสถานะที่อนุญาตเท่านั้น |
| B12 | ปิดโต๊ะ | ปิดรอบโต๊ะ ลูกค้ารอบใหม่เปิดบิลใหม่ ลูกค้ารอบเก่ายังดูใบเสร็จเดิมได้ |
| B13 | รีเฟรชไม่ทับข้อมูลใหม่ | ข้อมูลที่มาช้าห้ามเขียนทับสถานะล่าสุด และสลับบัญชีแล้วข้อมูลไม่ปนกัน |

## C. งานของเจ้าของร้าน

| # | ฟังก์ชัน | ผลที่ต้องได้ |
|---|---|---|
| C1 | จัดการเมนู | เพิ่ม แก้ชื่อ แก้ราคา จัดลำดับ (ทั้งหน้ารวมและในหมวด) ปิดขาย ลบและกู้คืน |
| C2 | จัดการขนาดและตัวเลือก | ขนาด ราคา เพิ่มพิเศษ ค่าเริ่มต้น จำนวนสูงสุด ข้อความหน้าลูกค้า พร้อมตัวอย่างก่อนบันทึก |
| C3 | บิลเก่าไม่เปลี่ยน | แก้ชื่อหรือราคาแล้ว บิลเดิมยังเป็นชื่อและราคาเดิม |
| C4 | แก้พร้อมกันสองเครื่อง | ถ้ามีคนแก้ก่อน ต้องให้โหลดใหม่ ไม่เขียนทับเงียบๆ |
| C5 | QR 10 ใบ | โต๊ะ 8 + กลับบ้าน 1 + LINE 1 พนักงานทุกคนดู ดาวน์โหลด คัดลอกได้ มีแค่ Owner ที่เปลี่ยน QR ได้ |
| C6 | ยอดขาย | รายวัน/เดือน กราฟรายชั่วโมง สัดส่วนช่องทางขายและวิธีจ่าย 10 เมนูขายดี (ไม่นับน้ำ/น้ำแข็งในอันดับ แต่นับในรายได้) |
| C7 | ส่งออก CSV | เปิดใน Excel ได้ ภาษาไทยไม่เพี้ยน ไม่มีตัวเลขวันเก่าปนวันใหม่ |
| C8 | ยอด Delivery | กรอกรายวันหรือนำเข้า CSV ยอดเดิมของวัน/ช่องทางถูกแทนที่ ไม่บวกซ้ำ |
| C9 | ลบประวัติยอดทดลอง | เฉพาะ Owner ต้องใส่เหตุผลและยืนยันสองขั้น เก็บบันทึกผู้ลบ/เวลา/รายการ ส่งซ้ำไม่ลบซ้ำ |
| C10 | ดูบัญชีพนักงาน | เห็น 6 บัญชีพร้อมบทบาทและสถานะ |
| C11 | การใช้โควตา | ขนาด DB/Storage ของ Supabase และข้อมูล Cloudflare ถ้าไม่มีข้อมูลให้แสดงว่าไม่มี ห้ามแสดงเป็น 0 |
