# เปิดเวอร์ชัน HTML

ดับเบิลคลิก `preview.html` แล้วเปิดด้วย Chrome, Edge หรือ Safari ได้เลย ไฟล์เดียวรวมหน้าจอ CSS JavaScript เมนู และกราฟทั้งหมด ไม่ต้องรัน server ติดตั้ง Node สมัคร Supabase/Cloudflare หรือต่ออินเทอร์เน็ต

## ลองกดได้

- เลือกอาหาร เลือกเส้น/ขนาด/ท็อปปิ้ง เพิ่มตะกร้า และส่งออเดอร์จำลอง
- กด “สลับหน้าจอ / โต๊ะ” ด้านบนเพื่อเลือกโต๊ะ 1–8 หรือสั่งกลับบ้าน และเปิด POS/ครัว/ยอดขาย
- หน้า POS เปิดเป็น Owner ตัวอย่างทันที ไม่ต้องเข้าสู่ระบบ หากลองออกจากระบบ รหัสทุกบัญชีทดลองคือ `1234`
- ลองเปลี่ยนสถานะ รับเงินจำลอง แก้ราคาเมนู และส่งออก CSV
- Dashboard มีข้อมูลตัวอย่างตั้งต้นให้เห็นหน้าตากราฟ ออเดอร์ที่ลองเพิ่มจะปรากฏใน POS และรวมยอดเมื่อกดรับชำระ
- ปุ่ม “เริ่มตัวอย่างใหม่” ล้างเฉพาะข้อมูล HTML ทดลอง แล้วกลับสู่ชุดตัวอย่าง

ข้อมูลอยู่ใน browser ของเครื่องนี้ ไม่ใช่ฐานข้อมูลร้าน ไม่รับเงินจริง ไม่ตรวจเงินโอน และไม่แชร์ออเดอร์ระหว่างโทรศัพท์คนละเครื่อง QR ที่สร้างเป็นลิงก์ไฟล์ตัวอย่าง ไม่ใช่ QR ออนไลน์สำหรับหน้าร้าน

เบราว์เซอร์ที่ไม่อนุญาต storage ใช้ข้อมูลในหน่วยความจำชั่วคราวและจะหายเมื่อปิดหน้า ส่วน browser ปกติจำข้อมูลทดลองไว้ด้วย localStorage โดยใช้ชื่อเฉพาะของ HTML นี้ แยกจากข้อมูล demo server เดิม

## ปรับแบบต่อ

ไฟล์ `preview.html` เป็นไฟล์ที่สร้างไว้สำหรับเปิดดู ช่วงแก้แบบเราปรับหน้าจอใน `src/pages/`, CSS ใน `src/styles/`, และข้อมูลตัวอย่างใน `preview/` แล้วสร้าง HTML ใหม่ด้วย:

```sh
pnpm preview:html
```

คำสั่งนี้ใช้สำหรับพัฒนาเท่านั้น ผู้เปิดดู HTML ไม่ต้องติดตั้งหรือรันคำสั่งใด

## สิ่งที่ตรวจแล้ว

- สร้าง bundle สำเร็จและผ่าน TypeScript check
- JavaScript ใน HTML ผ่าน syntax check ไม่มี script/CSS จาก CDN และไม่มี API fetch; CSP ปิด network connections
- ทดสอบ data adapter ในสภาพแวดล้อมจำลอง: เมนู 14 รายการ สลับกลับบ้าน สั่งอาหาร retry ไม่สร้างซ้ำ รับเงินจำลอง และเริ่มข้อมูลใหม่
- เครื่องมือ browser ใน Codex ไม่อนุญาต protocol `file:` จึงยังไม่ได้ตรวจการเปิดไฟล์นี้โดยตรงด้วยเครื่องมือนั้น ใช้ browser ของผู้ใช้เปิดด้วยการดับเบิลคลิกได้ตามปกติ

รุ่นก่อนก็เปิดในเครื่องได้โดยไม่สมัครบริการ แต่ต้องรัน Node/Vite ส่วน HTML นี้ตัดขั้นตอนนั้นออก การสมัคร hosting/database จะจำเป็นเมื่อเลือกนำระบบขึ้นออนไลน์ให้หลายอุปกรณ์ใช้ร่วมกัน
